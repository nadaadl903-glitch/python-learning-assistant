q4:what is the difference between a parameter and an argument?

Answer
A parameter is a variable declared within the function's definition, whereas an argument is a value passed to the function when it is called.

In other words, parameters are the input variables that are defined inside a function, whereas arguments are the values that are actually passed to the function when it's executed.

q9:how can you read a file in python?

Answer
You can read a file in Python by using the readlines() or read() methods.

To read all lines of a file at once, use the readlines() method, like this:

file = open("filename.txt", "r")
lines = file.readlines()
print(lines)
file.close()
To read a file line by line, use the readline() method, like this:

file = open("filename.txt", "r")
line = file.readline()
print(line)
file.close()
Alternatively, you can use the read() method to read the entire file at once, like this:

file = open("filename.txt", "r")
content = file.read()
print(content)
file.close()
